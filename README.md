# rpp-toolkit

Быстрый деплой [rustplusplus](https://github.com/alexemanuelol/rustplusplus) на свежий VPS.

Скрипт устанавливает Docker, запускает бота и при необходимости восстанавливает его данные из зашифрованного бэкапа.

Перед удалением VPS достаточно выполнить `rpp stop`. Данные будут зашифрованы и сохранены в приватный GitHub-репозиторий. На новом VPS они автоматически восстановятся.

## Как это работает

* бот запускается в Docker;
* данные хранятся на VPS в `/opt/rpp`;
* бэкап шифруется через GPG;
* зашифрованный архив хранится в отдельном приватном GitHub-репозитории;
* на новом VPS последний бэкап автоматически восстанавливается.

В публичном репозитории нет токенов и других секретов.

## Настройка

### 1. Создай свой репозиторий

Сделай fork этого репозитория или скопируй его себе на GitHub.

В `bootstrap.sh` укажи свой репозиторий:

```bash
TOOLKIT_REPO_RAW="${TOOLKIT_REPO_RAW:-https://raw.githubusercontent.com/YOUR_GH_USER/rpp-toolkit/main}"
```

### 2. Создай приватный репозиторий для бэкапов

Например:

```text
YOUR_GH_USER/rpp-data
```

Репозиторий должен быть **Private**. Оставь его пустым, первый бэкап создаст нужный файл сам.

### 3. Создай GitHub Token

Создай Fine-grained Personal Access Token с доступом только к `rpp-data`.

Нужное разрешение:

```text
Contents: Read and write
```

### 4. Подготовь Discord

В Discord Developer Portal создай приложение и получи:

* Bot Token
* Application ID (Client ID)

### 5. Создай пароль для бэкапа

Придумай длинный пароль и сохрани его в менеджере паролей.

Он используется для шифрования бэкапа и нигде не сохраняется.

### 6. Получи credentials rustplusplus

Выполни `rustplusplus credential application` и пройди настройку по инструкции самого бота.

Это нужно сделать один раз. После этого credentials будут попадать в бэкап.

## Установка

На новом VPS выполни:

```bash
curl -fsSL https://raw.githubusercontent.com/YOUR_GH_USER/rpp-toolkit/main/bootstrap.sh | \
  RPP_GH_TOKEN='ghp_xxxxxxxxxxxx' \
  RPP_DATA_REPO='YOUR_GH_USER/rpp-data' \
  RPP_BACKUP_PASSWORD='твой-пароль' \
  RPP_DISCORD_TOKEN='твой-discord-токен' \
  RPP_DISCORD_CLIENT_ID='твой-client-id' \
  sudo -E bash
```

Скрипт автоматически:

* установит Docker;
* создаст 1 GB swap на VPS с менее чем 1 GB RAM;
* установит команду `rpp`;
* восстановит последний бэкап, если он есть;
* запустит бота.

**Не сохраняй эту команду в истории shell на чужом VPS**, так как в ней находятся секреты.

## Команды

После установки доступна команда `rpp`:

```bash
rpp              # меню
rpp status       # статус и использование памяти
rpp logs         # логи
rpp restart      # перезапустить бота
rpp update       # обновить образ
rpp backup       # создать бэкап
rpp stop         # создать бэкап и остановить бота
rpp start        # запустить бота
```

## Перед удалением VPS

Перед тем как удалить сервер:

```bash
rpp stop
```

Команда создаст зашифрованный бэкап и загрузит его в `rpp-data`.

После этого VPS можно удалять.

На новом сервере снова запускаешь `bootstrap.sh` с теми же параметрами, и последний бэкап будет восстановлен автоматически.

## VPS с 512 MB RAM

Toolkit рассчитан в том числе на небольшие VPS.

Используется готовый Docker-образ, поэтому компилировать бота на сервере не нужно.

Также:

* контейнер ограничен 400 MB RAM;
* для Node установлен лимит `300 MB`;
* на VPS с менее чем 1 GB RAM создаётся 1 GB swap;
* Docker-логи ограничены, чтобы не забивать диск.

## Безопасность

Бэкап хранится в GitHub только в зашифрованном виде.

GitHub Token рекомендуется ограничить одним репозиторием `rpp-data` и правами `Contents: Read and write`.

Пароль шифрования не хранится в репозитории и нужен для восстановления данных.

Если кто-то получит доступ к VPS до его удаления, он потенциально сможет получить доступ к данным, пока они находятся на сервере. Поэтому после `rpp stop` VPS можно удалять.
